# 🔍 Image Fraud Detector

**Lenovo Premier Support · AI Forensic Analysis Engine · v1.0**

A professional-grade fraud detection tool built for Lenovo TSS (Technical Support Specialists) to identify AI-generated or AI-altered images submitted by customers in warranty and support claims. Designed to mirror the Lenovo OCM QuickCheck v2 aesthetic and workflow.

---

## 🧠 Background

As AI image generation becomes increasingly accessible, Lenovo Premier Support teams began receiving customer-submitted photos that had been altered or entirely generated by AI — used to misrepresent device conditions and fraudulently obtain warranty coverage.

This tool was developed in response to a real internal fraud alert (April 2026) flagged by the Lenovo Premier Support TAM team, identifying manipulated monitor photos submitted as warranty evidence. It provides TSS agents with a fast, reliable way to score submitted images before processing claims.

---

## ✨ Features

### 🤖 AI Forensic Analysis
- Powered by **Claude Sonnet** (Anthropic API) with vision capabilities
- Evaluates 8 forensic indicators per image:
  - Text Integrity — distorted or gibberish taskbar/icon text
  - UI Consistency — duplicate Start buttons, repeated icons
  - Window Content — suspiciously blank open windows
  - Timestamp/Clock — unreadable or nonsensical dates
  - Icon Labels — corrupted or misspelled desktop labels
  - Overall Coherence — unnatural artifacts or lighting
  - Edit Artifacts — JPEG inconsistencies, mismatched noise
  - Context Match — does the image support the customer's claim?

### 🌡️ ELA Heatmap (Error Level Analysis)
- Fully **client-side**, no API call required
- Uses Canvas API to re-compress the image at 75% JPEG quality and pixel-diff against the original
- Maps compression differences to a **thermal color scale** — bright regions indicate tampered or AI-generated areas
- Adjustable sensitivity slider (1x–20x amplification)
- Color legend included for agent reference

### 📊 Fraud Risk Score System
Every image receives a **0–100 Fraud Risk Score** with automatic tier classification:

| Score | Color | Tier | Action |
|-------|-------|------|--------|
| 0–30 | 🟢 Green | Auto-Cleared | Proceed with claim |
| 31–60 | 🟡 Amber | Agent Review Recommended | Manually inspect before proceeding |
| 61–85 | 🟠 Orange | Flag for Review | Escalate to TAM or technical lead |
| 86–100 | 🔴 Red | Auto-Hold / Escalate to TAM | Do not proceed, flag the case |

### 📋 Agent Workflow Tools
- **Agent Notes** field for documenting observations per submission
- **Copy to Clipboard** — formats Case ID, score, verdict, summary, and recommendation into a paste-ready MSD case note
- **Auto-generated Case ID** (format: `TSS-XXXXXXXX`) for audit trail tracking
- **Analysis timestamp** on every result for record keeping

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- Python 3.9+
- Anthropic API key

### Installation

```bash
# Clone the repo
git clone https://github.com/Jefferz58/TSS-Image-Fraud-Detector.git
cd TSS-Image-Fraud-Detector

# Install frontend dependencies
cd frontend
npm install

# Install backend dependencies
cd ../backend
pip install -r requirements.txt
```

### Environment Setup

Create a `.env` file in the `backend` directory:

```env
ANTHROPIC_API_KEY=your_api_key_here
```

### Running Locally

```bash
# Start backend
cd backend
python server.py

# Start frontend (new terminal)
cd frontend
npm start
```

## 🔒 Privacy & Ethics

- Image analysis runs through the Anthropic API — do not submit images containing PII beyond what is already present in the support case
- The fraud scoring system is intended as a **decision-support tool**, not a final determination — all flagged cases should receive human review
- Customers are not notified of image scanning, consistent with standard enterprise fraud prevention and support agreement terms
